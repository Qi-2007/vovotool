沃沃头是一款第三方 原神 LSPosed 拓展模块，让你在原神安卓端上启用 PC 界面、原生键鼠操作，并提供画面调整功能和便携工具。

## 功能

应用底部分为 **首页、管理、关于**。首页查看游戏连接状态，管理页按四类功能调整设置。

### 画面

- **渲染分辨率**：按比例调整，也可手动输入宽高。
- **帧率上限**：跟随游戏，或选择 30 / 45 / 60 / 90 / 120 / 144 / 165 FPS。
- **特效增强**：提高部分特效的渲染尺寸。
- **植被与关联距离**：在 10%～100% 之间调整。
- **反角色虚化**：镜头靠近角色时保持角色可见。

### 操控

- **PC 界面与原生键鼠**：使用游戏内的键鼠操作方式，支持 Enter、Esc 与地图鼠标操作。
- **自动捕获指针**：操作镜头时捕获指针，打开菜单时释放。
- **镜头速度**：分别调整鼠标基础倍率与触控板倍率。
- **触控板兼容**：为 Lenovo 键盘套触控板提供相对鼠标输入。

### 其他功能

- 本拓展模块还会提供一些其他功能，请自行探索~

## 安装与启用

### 运行环境

| 项目 | 要求 |
| --- | --- |
| Android | 8.0 及以上，ARM64 |
| 模块框架 | 已配置 LSPosed |
| 游戏 | 原神国服 `com.miHoYo.Yuanshen` |
| 当前适配版本 | `7.2.0_48751704_49008628` |
| 图形设置 | 分辨率与特效增强使用 Vulkan 渲染路径 |

### 使用方法

1. 安装沃沃头 APK。
2. 在 LSPosed 中启用「沃沃头」，作用域勾选「原神」。
3. 打开沃沃头，在 **管理 → 操控** 中启用「PC 界面与原生键鼠」。
4. 连接键盘与鼠标，重新启动原神。
5. 回到沃沃头首页，可查看游戏连接状态。

使用 Lenovo 磁吸键盘的触控板时，如遇无法移动镜头，可以在 **管理 → 操控 → 触控板兼容** 中点击「启动触控板兼容」，授予 root 权限后进入游戏。

## 功能等级

首次打开时为等级 0，管理页显示画面与操控。进入「关于」，连续点击 Logo，可切换功能等级：

| 当前等级 | 操作 | 结果 |
| --- | --- | --- |
| 0 | 点击 5 次后停顿约 1 秒 | 启用高级功能，进入等级 1，显示并启用便携功能 |
| 1 | 点击 8 次后停顿约 1 秒 | 弹出验证码框，输入 `0329` 并按回车，进入等级 2，显示并启用其他功能 |
| 1 或 2 | 点击 5 次后停顿约 1 秒 | 返回等级 0，隐藏并停用便携功能与其他功能 |

达到次数后停下来才会触发，继续点击会取消该次待触发操作。等级会保留，下次打开应用继续使用；各功能仍按自己的开关设置生效。

## 使用说明

### 调整画面

在 **管理 → 画面** 中启用自定义图形设置，调整参数后点击「保存图形设置」，手动重新启动原神后才会生效。选择「恢复游戏原值」后，同样在下次启动时应用。

分辨率支持 5% 步进缩放，也可手动输入。宽高需为 4 的倍数，至少 1280×720，最高为屏幕原生尺寸；应用会在保存时检查输入。帧率选项设置的是上限，实际帧率随设备性能和游戏负载变化。

反角色虚化和镜头速度等设置可在游戏运行时调整，通常约 1 秒生效。

### 设置快捷键

在对应的便携功能卡片中点击「设置快捷键」，按下要使用的按键或组合键即可保存。按 `Esc` 取消录制，每项功能需使用不同的快捷键。

回到大世界可操作状态后按对应的快捷键即可使用。

### 扫码登录

在 **管理 → 其他功能** 中开启扫码登录后，可以在游戏账号弹窗页面点击左上角的「扫码登录」 按钮，使用手机原神或米游社扫描并确认。二维码过期后可点击刷新。

## 常见问题

**首页一直显示等待连接？**

确认 LSPosed 已启用沃沃头，作用域已勾选原神。打开一次沃沃头，再完全退出并重新启动游戏，同时核对上方列出的适配版本。

**修改画面后不生效？**

点击「保存图形设置」后重新启动原神。更新模块 APK 后，也需要重新启动游戏以加载新版本。


**怎样停止使用模块？**

在 LSPosed 中停用沃沃头，再重新启动原神。触控板辅助可在应用中点击「停止触控板兼容」。

## 开发与反馈

本项目使用 Java 原生 View 与 C++，通过 Python 脚本构建。在 Windows 上准备 Python 3.11 及以上版本后，于项目根目录运行：

```powershell
python tools/setup_toolchain.py
python tools/build.py
```

构建产物位于 `dist/`。工具链、模块结构与历史适配记录见 [开发文档](docs/development-notes.md)。

反馈问题时，请附上设备型号、Android 版本、原神版本、模块版本、复现步骤，以及相关截图或 LSPosed 日志。
