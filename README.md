沃沃头是一款第三方 原神 LSPosed 拓展模块，让你在原神安卓端上启用 PC 界面、原生键鼠操作，并提供画面调整功能和便携工具。

## 功能

应用底部分为 **首页、管理、关于**。首页查看游戏连接状态，管理页按功能分类调整设置。

主页面支持左右拖动切换；管理页内容区可左右拖动切换功能分类。底部导航和分类胶囊也支持拖动，松手后吸附到目标项。

### 画面

- **渲染分辨率**：按比例调整，也可手动输入宽高。
- **帧率上限**：跟随游戏，或选择 30 / 45 / 60 / 90 / 120 / 144 / 165 FPS。
- **特效增强**：提高部分特效的渲染尺寸。
- **植被与关联距离**：在 10%～100% 之间调整。
- **反角色虚化**：镜头靠近角色时保持角色可见。

### 操控

- **PC 界面与原生键鼠**：使用游戏内的键鼠操作方式，支持 Enter、Esc 与地图鼠标操作。
- **自动捕获指针**：操作镜头时捕获指针，打开菜单时释放；按住 ALT 临时释放光标，松开恢复。地图页鼠标可直接拖动（鼠标事件会转为触摸）。
- **镜头速度**：分别调整鼠标基础倍率与触控板倍率。
- **触控板兼容**：为 Lenovo 键盘套触控板提供相对鼠标输入。

### 其他功能

- 本拓展模块还会提供一些其他功能，请自行探索~

## 安装与启用

### 运行环境

| 项目 | 要求 |
| --- | --- |
| Android | 8.0 及以上，ARM64 |
| 模块框架 | 已配置 LSPosed |
| 游戏 | 原神国服 `com.miHoYo.Yuanshen`；原神国际服 `com.miHoYo.GenshinImpact`（见下方适配状态） |
| 当前适配版本 | `7.2.0_48751704_49008628`（国服与国际服同为 7.2） |
| 图形设置 | 分辨率与特效增强使用 Vulkan 渲染路径 |

### 使用方法

1. 安装沃沃头 APK。
2. 在 LSPosed 中启用「沃沃头」，作用域勾选「原神」。
3. 打开沃沃头，在 **管理 → 操控** 中启用「PC 界面与原生键鼠」。
4. 连接键盘与鼠标，重新启动原神。
5. 回到沃沃头首页，可查看游戏连接状态。

设置会自动保存，之后直接启动原神即可加载，无需先打开沃沃头。

使用 Lenovo 磁吸键盘的触控板时，如遇无法移动镜头，可以在 **管理 → 操控 → 触控板兼容** 中打开「启用触控板兼容」，首次启用时授予 root 权限。开关会保存，之后启动游戏会自动连接。

## 国际服适配状态

本分支在原版国服支持的基础上，增加了对**原神国际服** `com.miHoYo.GenshinImpact`（7.2.0）的适配。国服与国际服使用**同一个 APK**，无需分别构建；在首页顶部的区服选项卡中选择目标区服即可，选择会持久化，两服配置（`settings_cn` / `settings_os`）独立保存。模块在运行时自动识别当前游戏并加载对应偏移表。

当前各项功能的实测状态如下：

| 功能 | 国际服状态 | 说明 |
| --- | --- | --- |
| 模块加载与稳定性 | ✅ 可用 | 已修复三处函数地址误判导致的启动崩溃，可正常进入游戏 |
| 帧率上限 | ✅ 可用 | 在沃沃头中设置并保存后重启游戏生效；实际帧率受设备性能与负载限制 |
| 渲染分辨率 | ✅ 可用 | UI 与场景渲染目标均按设置改写，需 Vulkan 渲染路径 |
| 特效增强 / 植被距离 | ✅ 可用 | 画质参数随图形设置一并下发 |
| **PC 界面与原生键鼠** | ✅ 可用 | PC 界面、Enter/Esc 键、鼠标转视角均已适配；键盘走映射表、鼠标走轴数组注入，经真机验证；ALT 临时释放、聊天框光标切换、地图鼠标拖动、加载页不误独占均已修复 |

也就是说：**国际服的画质功能与 PC 键鼠功能均已可用**。国服的全部功能不受影响。

> 国际服函数地址来自同节区锚点投票与逐指令校验，并经过真机验证；详细的定位依据、验证数据与遗留问题见 [国际服适配修复记录](docs/international-port-fix.md)。

> 鼠标独占状态根据游戏原生 UI 页面栈深度判定：世界场景保持独占并转视角，打开抽卡/设置/角色面板等页面自动释放光标，关闭页面后自动重新独占。加载与登录页面不会被误判为大世界，进入大世界后才自动独占。
>
> ALT 临时释放、回车打开聊天框的光标切换均已支持；地图页鼠标事件会转为触摸，可直接拖动地图。
>
> 已知小限制：聊天框内打开表情面板或切换好友时，鼠标可能被重新捕获；按 ESC 或点击输入框即可继续操作，无需重启游戏。

## 功能等级

首次打开时为等级 0，管理页显示画面与操控。进入「关于」，连续点击 Logo，可切换功能等级：

| 当前等级 | 操作 | 结果 |
| --- | --- | --- |
| 0 | 点击 5 次后停顿约 1 秒 | 启用高级功能，进入等级 1，显示并启用便携功能与其他功能 |
| 1 | 点击 8 次后停顿约 1 秒 | 弹出验证码框，输入 `0329` 并按回车，进入等级 2，显示实验功能页（暂未添加内容） |
| 1 或 2 | 点击 5 次后停顿约 1 秒 | 返回等级 0，隐藏并停用便携功能与其他功能 |

达到次数后停下来才会触发，继续点击会取消该次待触发操作。等级会保留，下次打开应用继续使用；各功能仍按自己的开关设置生效。

## 使用说明

### 调整画面

在 **管理 → 画面** 中启用自定义图形设置，调整参数后点击「保存图形设置」，手动重新启动原神后才会生效。选择「恢复游戏原值」后，同样在下次启动时应用。

分辨率支持 5% 步进缩放，也可手动输入。宽高需为 4 的倍数，至少 1280×720，最高为屏幕原生尺寸；应用会在保存时检查输入。帧率选项设置的是上限，实际帧率随设备性能和游戏负载变化。

反角色虚化和镜头速度等设置可在游戏运行时调整，通常约 1 秒生效。

### 设置快捷键

在对应的便携功能卡片中点击「设置快捷键」，按下要使用的按键或组合键即可保存。按 `Esc` 取消录制，每项功能需使用不同的快捷键。

回到大世界可操作状态后按对应的快捷键即可使用。

### 扫码登录

在 **管理 → 其他功能** 中开启扫码登录后，可以在游戏账号弹窗页面点击左上角的「扫码登录」 按钮，使用手机原神或米游社扫描并确认。二维码过期后可点击刷新。

## 常见问题

**首页一直显示等待连接？**

确认 LSPosed 已启用沃沃头，作用域已勾选原神。完全退出并重新启动游戏，同时核对上方列出的适配版本。

**修改画面后不生效？**

点击「保存图形设置」后重新启动原神。更新模块 APK 后，也需要重新启动游戏以加载新版本。


**聊天框里点表情/切好友后鼠标被锁住了？**

聊天框内的部分操作会让模块重新捕获指针。按 ESC 退出聊天框，或点一下输入框即可恢复；不影响游戏本体。

**怎样停止使用模块？**

在 LSPosed 中停用沃沃头，再重新启动原神。触控板辅助可在应用中关闭「启用触控板兼容」。

## 开发与反馈

本项目使用 Java 原生 View 与 C++，通过 Python 脚本构建。在 Windows 上准备 Python 3.11 及以上版本后，于项目根目录运行：

```powershell
python tools/setup_toolchain.py
python tools/build.py
```

在 Linux 上使用 `tools/build_linux.py`（工具链默认在 `~/work/toolchain-linux`，可用 `VOVOTOOL_TC` 覆盖）：

```sh
python3 tools/build_linux.py
```

构建产物位于 `dist/`。工具链、模块结构与历史适配记录见 [开发文档](docs/development-notes.md)。

反馈问题时，请附上设备型号、Android 版本、原神版本、模块版本、复现步骤，以及相关截图或 LSPosed 日志。
