# 实验功能：红圈解锁

在「管理 → 实验功能」中点击「解锁红圈」，一次性将本地开放状态
47、48、7058 设为 true，分别对应新手、大世界和至冬区域限制。页面回读三个状态后
显示执行结果。操作主开关需开启；重新登录后可再次执行。

请求只保存在当前模块进程中，60 秒过期，不写入偏好设置。游戏侧收到新请求后，
在现有游戏 Tick 中执行一次；重复配置轮询不会重复调用。降低开发者等级或关闭
操作主开关会取消尚未执行的请求。已执行的状态由游戏后续同步处理。

当前国服 7.2 ARM64 调用入口为 `HBIJFOJIFAH.DHCGAPDLMLL`，RVA `0xce1aa5c`，
签名为 `void(manager, uint32_t stateId, bool active, MethodInfo*)`。接收对象来自
`*(root+0x8c40)`，状态对象来自 `*(manager+0x70)`。调用前检查函数指纹、对象类型、
字典布局和三个状态条目，调用后重新读取缓存。使用本地状态入口，不会提交开放状态请求。
